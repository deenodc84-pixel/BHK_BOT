# 🏀 BallHK - Basketball Companion Bot

A Telegram bot for basketball fans providing NBA stats, player information, game schedules, and trivia.

## Features
- NBA champion history
- Player statistics
- Team listings
- Upcoming games
- Basketball trivia
- Fun facts
- All-time records
